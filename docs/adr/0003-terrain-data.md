# ADR-0003: 地形データにオープンデータを採用し、自前タイルパイプラインを組む

- **状態**: 承認
- **日付**: 2026-08-01
- **決定者**: ユーザー（選択肢提示に対する裁定）

## 背景

「実在地形・都市をベースにした地球規模マップ」が要件。データ調達には大きく2ルートある。

- **商用タイルサービス**（Cesium ion / Google Photorealistic 3D Tiles）: フォトグラメトリ製の実在都市 3D が即座に使える。品質は圧倒的。ただし API キー必須、従量課金、商用配布時のライセンス制約。
- **オープンデータ + 自前パイプライン**: 無償・再配布可。ただしタイル生成・簡略化・テクスチャ合成を自前で組む工数がかかる。

## 決定

**オープンデータを採用する。**

| 種別 | ソース | 解像度 | ライセンス |
|---|---|---|---|
| 標高 | Copernicus DEM GLO-30 | 全球 30m | 無償・再配布可 |
| 空港・滑走路・taxiway | OpenStreetMap (`aeroway=*`) | ベクタ | ODbL（帰属表示要） |
| 建物フットプリント | OpenStreetMap (`building=*`) | ベクタ | ODbL |
| 地表画像（高解像） | Sentinel-2 L2A | 10m | 無償 |
| 地表画像（全球ベース） | Natural Earth II | 低解像 | パブリックドメイン |
| 土地被覆 | ESA WorldCover | 10m | CC BY 4.0 |

決め手は、API キー・課金・配布制約がプロジェクトの前提に入らないこと。個人開発で従量課金が走る構造は、開発中の反復（タイルを何度も焼き直す）と特に相性が悪い。

## タイルスキーム

**地理座標系クアッドツリー**（Cesium geographic tiling scheme と同一）を採用する。

```
level 0:  2 タイル × 1 タイル   各 90° × 90°... ではなく 180°×180°を経度2分割
          tile(0,0) = lon[-180,0]  lat[-90,90]
          tile(1,0) = lon[   0,180] lat[-90,90]
level n:  2^(n+1) × 2^n タイル
```

Web メルカトルではなく地理座標系にする理由: メルカトルは極域が表現できない（±85°で打ち切り）。地球全体を飛ぶ要件と両立しない。

既存の Cesium 形式と互換にしておくことで、将来「やはり商用タイルも併用したい」となった際に**タイル索引の設計を作り直さずに済む**。この互換性は意図的に確保している。

## LOD

**幾何誤差ベースの screen-space error** で選択する。距離ベースではない。

```
sse = (geometric_error * viewport_height) / (distance * 2 * tan(fov/2))
if sse > threshold: 子タイルへ細分化
```

理由: 平野と山岳では同じ距離でも必要ポリゴン数が桁で違う。距離ベースだと平野で過剰に細分化し、山岳で不足する。タイル生成時に実際の標高分散から `geometric_error` を算出して埋め込む。

## パイプラインの段階

```
[生データ] --(オフライン)--> [中間タイル] --(オフライン)--> [実行時タイル] --(実行時)--> [メッシュ]
 GeoTIFF                      正規化 f32 heightmap        量子化 + 圧縮        頂点バッファ
 OSM PBF                      タイル境界でクリップ         幾何誤差を付与
```

**オフライン処理と実行時を明確に分ける。** 実行時に GeoTIFF をパースするような設計にしない（フレーム予算に収まらない）。

## 帰結

**受け入れるコスト**
- フォトグラメトリ都市は手に入らない。建物は OSM フットプリント + 高さ属性からの押し出し（procedural）になる。見た目の作り込みでは商用タイルに明確に劣る。
- タイル生成パイプライン（GeoTIFF 読込、再投影、簡略化、量子化）を自前実装する必要がある。これは `world` 担当の主要工数。
- 全球 30m DEM の生データは圧縮済みでも数百 GB 規模。**全球を一度に焼く前提にしない** — 対象地域を指定して焼く CLI ツールを先に作り、M1 では 1 空港周辺のみを対象にする。

**帰属表示の義務**
- OSM (ODbL) と ESA WorldCover (CC BY 4.0) は帰属表示が必須。`ATTRIBUTION.md` を作成し、ゲーム内のクレジット画面にも表示すること。**これは法的義務なので実装漏れを許さない。**

## 差し戻し条件

以下が起きた場合、この決定を再評価する。
- 都市部の見た目が要件を満たさないとユーザーが判断した場合 → Cesium ion / Google 3D Tiles の併用を検討（タイル索引が互換なので差し替え可能）
