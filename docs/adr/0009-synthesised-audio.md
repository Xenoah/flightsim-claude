# ADR-0009: 音を同梱ファイルではなく合成で作り、`flightsim-audio` に置く

- 状態: 採用
- 日付: 2026-09-01
- 関連: [ADR-0003](0003-terrain-data-source.md)（オープンデータ方針）、
  [ADR-0007](0007-bevy-version.md)（Bevy の feature を明示列挙する）

## 背景

音が一切無かった。`bevy_audio` も入っていなかった。

一番効くのは**失速警報**である。失速が近いことを知る手段が、無音では
「計器を見る」しかない。着陸の最終段階で計器を見ている余裕は無く、実機に
必ず失速警報が付いているのはそのためである。エンジン音と風切り音も同じで、
出力と速度を耳で追えると、視線を外に置いたまま機体の状態が分かる。

## 決定 1: 音源はコードで合成する。音声ファイルを同梱しない

### 理由

**音声ファイルを持ち込むと、出所と再配布条件の判断が要る。** それは実装とは
別の判断で、追加機体（[Issue #10](../../../issues/10)）とコックピット内装が
「調達待ち」で止まっているのと同じ轍になる。ADR-0003 でデータ源に同じ判断を
しているので、方針としても一貫する。

合成なら:

- 誰の権利にも触らない。配布物に第三者の素材が入らない
- 生成が決定論的。同じ設定で必ず同じ音になり、「さっきと違う音がした」が
  不具合の兆候として意味を持つ
- 検査できる。波形の性質（ループの継ぎ目、振幅の余裕、WAV ヘッダの整合）を
  純関数として突ける

### 引き受ける代償

**実機を録音した音には敵わない。** これは承知のうえで選んでいる。
目指しているのは「本物らしい音」ではなく、**計器を見なくても機体の状態が
分かること**である。ここを取り違えて「もっとリアルな音に」と作り込むと、
合成では届かない目標を追うことになる。

将来、権利の判断が済んだ音源を使うと決めたなら、[`engine`] を差し替えれば
よい。鳴らし方（音量と再生速度の決め方）はそのまま使える。

## 決定 1-b: 波形 1 本を再生速度で回すのをやめ、毎標本その場で作る（2026-09-02 改訂）

### 最初の作りと、それが駄目だった理由

最初は「波形を 1 本作ってループ再生し、再生速度でピッチを上げ下げする」
形だった。**これはビープ音にしかならなかった。** 理由は 2 つある。

**1. 正弦波の重ね合わせでは、エンジンの音にならない。**
エンジンの音は持続する倍音ではなく、**排気の圧力パルスの連なり**である
（[PTR 論文]）。正弦波を足すと、周波数構成は合っていても「オルガン」になる。

**2. 再生速度でピッチを変えると、音色まで一緒に伸び縮みする。**
実機は回転を上げても排気管や機体の共鳴は動かない。全部まとめて移調させると
「テープの早送り」に聞こえる。出力が変わったときにパルスの形を変えることも
できない（実機は筒内圧が上がると排気の立ち上がりが鋭くなり、音が硬くなる）。

### 今の作り: Pulse-Train-Resonator

点火のたびにパルスを立て、それを共鳴に通す。構造は [PTR 論文] の
モデルを非学習で書き下したもの。

| 段 | 何をするか |
|---|---|
| 点火位相 | エンジン 1 サイクルを 0→1 で回し、気筒を等間隔に置く |
| 圧力開放エンベロープ | `(1 - e^{-aφ}) · e^{-bφ}`。急に開いてゆっくり抜ける非対称な形 |
| 熱力学的位相変調 | `φ^n`。燃焼直後の高温ガスは音速が高く、抜けるにつれ下がる |
| 排気管の共鳴 | 遅延線と減衰（Karplus-Strong）。「管を通った音」になる |
| フォルマント | 320 Hz / 650 Hz / 1150 Hz の固定共鳴 |
| プロペラ | 羽根通過の周期で強弱を付けた空気の音 |
| 広帯域 | 吸気（出力に付く）と後流（回転数に付く） |

**要点は「動く倍音列と、動かない共鳴」の組み合わせ**である。回転数は
パルスの間隔だけを変え、共鳴はその場に留まる。これが「物体が鳴っている」
という印象を作る。共鳴まで回転数に追従させると、全体が移調するだけの
電子音に戻る。

### 周波数は諸元から出す

対象は Lycoming O-320 相当（水平対向 4 気筒・4 サイクル・空冷・**直結駆動**、
150 hp / 2700 rpm、固定ピッチ 2 枚羽根）。

| 音源 | 式 | 2400 rpm での値 |
|---|---|---|
| 排気の点火周波数 | `rpm × 気筒数 / 2 / 60` | 80 Hz |
| プロペラ BPF | `rpm × 羽根数 / 60` | 80 Hz |

**この構成では両者が一致する**（どちらも `rpm/30`）。軽単発機のあの唸りは
この重なりである。検査で固定してある。

### 実測で確かめたこと

同じ飛行を書き出して、スペクトルを測って直した。

| | 最初（正弦波の和） | 今 |
|---|---|---|
| 最強成分がエネルギーに占める割合 | 0.27 | 0.10〜0.18 |
| 上位 10 本の合計 | 0.82 | 0.50 |
| 100 Hz 以下の割合（全開） | 0.74 | 0.34〜0.48 |
| 300〜1000 Hz | 0.035 | 0.11〜0.19 |

**「それらしい音がする」ではなく数字で確かめている。** 検査には
Goertzel 法を自前で置いてあり（FFT の依存を増やさずに 1 本の周波数だけ測る）、
点火周波数に山が立つこと、出力を上げると倍音の比が変わること、
失速警報が全開・高速でも 19 倍の差で立つことを固定してある。

### 音の thread では鍵を使わない

rodio は自前の thread で標本を取りに来る。**そこで鍵（Mutex）待ちが起きると、
その瞬間に出力が途切れて「プツッ」と鳴る。** ECS からの値渡しは原子変数で行う。

### そのほか、作り方で決めたこと

- **`rand` を持ち込まない。** 決定論のため、xorshift64 を自前で持つ
- **NaN を状態に居座らせない。** フィルタの状態に一度入ると以降ずっと
  無音になり、原因のフレームはとっくに過ぎているので追えなくなる
- **振幅に余裕を残し、頭は `tanh` で丸める。** 3 つ足して 1 を超えたときに
  切ると、一番大きい音が一番耳障りな形で歪む
- **消音は音量を落とすだけ。音源は回し続ける。** 止めて作り直すと、
  再開のたびに位相が飛んで「ブツッ」と鳴る

## 決定 1-c: 戦闘機（ターボファン）の音を足し、既定にする（2026-09-03 改訂）

### 何が違うのか

ピストンは**離散した爆発の連なり**で、点火周波数（最大 90 Hz）とその倍音が
骨格になる。タービンは**連続燃焼と、回転する翼列**が音を作る。
**骨格になる周波数が 2 桁違う。**

| 音源 | 周波数 | 由来 |
|---|---|---|
| ファンの翼通過音 | `羽根数 × N1/60` | **「キーン」の正体。** 4.3〜7.1 kHz |
| バズソー | `N1/60` の倍音 | **翼端が超音速のときだけ**出る |
| 圧縮機の翼通過音 | `羽根数 × N2/60` | さらに高い |
| 排気の混合音 | `0.2 × 排気速度 / ノズル径` | 広帯域の「ゴー」。50〜300 Hz |
| アフターバーナー | 広帯域 + 低い唸り | 点火で一段大きくなる |

### バズソーが要点

ファン翼端が音速を超えると、各翼の衝撃波が前方へ抜ける。翼の製造ばらつきで
1 枚ずつ強さが違うため、**翼通過周波数ではなく軸回転周波数の倍音**に
エネルギーが並ぶ。あの濁った「ガーッ」はこれで、翼通過音の澄んだ「キーン」
とは別物である。**両方要る**——翼通過音だけだと電子的な単音になり、
バズソーだけだと何の音か分からなくなる。

### 諸元の出どころ

| 値 | 出どころ |
|---|---|
| ファン 32 枚 | F110-129 第 1 段の公表値 |
| 最大 N1 13,270 rpm | F404 の設計点 |
| N2/N1 = 1.27 | F404 の 16,810 / 13,270 |
| 排気ピーク = `0.2 u/d` | Strouhal 数 0.2 |
| 強度が速度の 6 乗 | 加熱ジェットの scaling |
| ノズル径・排気速度・アイドル N1 | **代表値。特定の実機を写していない** |

**強度が 6 乗なら振幅は 3 乗。** 強度をそのまま振幅に使うと、
アフターバーナーで 10 倍以上に跳ねて割れる。

### スプールの遅れ

**タービンは回転が上がるのが遅い。** アイドルから軍用推力まで数秒かかるのが
特徴で、そこを即座に追わせると別の乗り物の音になる。上りと下りで時定数を
分けてある（上り 2.6 秒、下り 1.6 秒）。

### 実測で合わせたこと

| | 値 |
|---|---|
| アイドル | 4〜9 kHz が 94%（純粋なファンの笛。実機の地上アイドルもそう） |
| 軍用推力 | 4〜9 kHz が 65%。巡航の「キーン」 |
| アフターバーナー | 20〜200: 0.19、200〜1k: 0.34、1〜4k: 0.15、4〜9k: 0.24 |
| 点火の効き | 軍用推力の **1.65 倍**（実効値） |
| ピストンとの明るさの差 | 3 kHz 以上の実効値で **2.5 倍** |

**途中で 2 回作り直している。**
1 度目はファンを厚くしすぎて 4 kHz 以上が 98% を占め、ジェットではなく
単なる高い笛になった。2 度目はアイドルの排気を絞りすぎて、アイドルが
やはり笛になった。**「キーンとしている」と「笛」は紙一重で、
排気の広帯域と釣り合って初めてジェットに聞こえる。**

### 既定をタービンにした

戦闘機の方向で進めるという判断による。ピストンは `--engine piston` で残してある。

**飛び方は変わらない。** FDM は 160 hp のピストン単発
（`AircraftConfig::light_single`、プロペラ効率 0.8、1043 kg、翼幅 11 m）を
解いており、音だけがタービンになる。**音と物理が食い違っている状態**で、
これは承知のうえの選択である。機体ごと変えるには FDM の推力モデル・
性能諸元・3D モデルが要る。

## 決定 2: `flightsim-audio` を新設し、render / input / ui と同階層に置く

```text
            app (Bevy)
                │
  render / input / ui / audio   ← Bevy 依存層。互いに依存しない
                │
               sim
```

### なぜ既存のクレートに入れないか

- `flightsim-render` は描画。音は描画ではない。名前が実態と食い違う
- `flightsim-ui` は HUD と計器。音は画面に出るものではない
- `flightsim-sim` は Bevy 非依存の統合層。`bevy_audio` を入れると
  [ADR-0001] の規約（純 Rust 5 クレートに bevy を依存させない）を破る

同階層の兄弟として置くのが、依存規約（[ARCHITECTURE.md] §2）に沿う唯一の形。
`scripts/check-architecture.sh` にも `audio` を横断禁止の対象として足した。

### 波形の合成も同じクレートに置く

合成そのものは Bevy 非依存の純 Rust だが、**別クレートには割らない。**
今のところ合成した音を使うのは鳴らす側しかなく、割ると「どちらに何が
あるか」を覚える手間だけが増える。

そのかわり**モジュールの境界で Bevy を分けてある**: `dsp` / `engine` /
`airframe` / `mixer` は Bevy に触れず、Bevy へ繋ぐのは `source` だけ。
おかげで音そのものは GUI 無しで検査でき、
`cargo run -p flightsim-audio --example render_engine` で WAV に書き出して
聞き比べられる。

## 決定 3: 失速警報の判定は迎角で行う

**失速は迎角の現象で、速度の現象ではない。** 対気速度で判定すると、
旋回中（荷重倍数が増えて失速速度が上がる）や追い風で外れる。

判定に使う迎角は `Simulation::stall_fraction` が出す。積分の中で使っている
式と同じ関数（`flightsim_fdm::aero_angles_of`）を呼ぶ。**別に書き直さない。**
片方だけ直されると、警報が鳴るのと実際に失速するのがずれ、警報が信用されなくなる。

鳴り始めと鳴り止みで閾値を分ける（0.85 / 0.78）。同じ値にすると、境界上で
迎角が揺れるたびに鳴ったり止まったりする。

## 何を写していないか

- **排気管の形状も長さも実機から取っていない。** 共鳴周波数は
  「軽単発機の音が乗っている帯域」に置いた値で、実測でも設計値でもない
- **回転数は FDM が持っていない。** `EngineConfig` は軸出力で推力を出す
  モデルで、回転数という状態が無い。音のためだけに、固定ピッチプロペラの
  振る舞いを模した推定を `engine::estimate_rpm` に置いてある。
  **飛び方には一切影響しない**が、実機の回転計と突き合わせられる値ではない
- 気筒ごとの点火間隔のばらつき、失火、混合比の影響
- プロペラ後流と機体の干渉音、翼面での反射
- ドップラー、位置による定位、コックピット内外での音のこもり。
  視点が変わっても音は同じ
- 接地音、フラップやギアの作動音、無線

## 決めていないこと

- **実際に聞いて調整していない。** スペクトルは測って直したが、
  「気持ちよく聞こえるか」は測れない。音量の釣り合い、回転数の幅、
  フォルマントの位置は、鳴らして判断する必要がある
