# ADR-0006: 地形と FDM の結線を `flightsim-sim` に置く

- **状態**: 承認
- **日付**: 2026-08-06

## 背景

M1 の完了条件は「ヘッドレスで実地形の上を物理的に妥当に飛ぶ軌跡を出力できること」。
FDM（[TASK-1](../HANDOFF.md)）と地形タイル（[ADR-0005](0005-runtime-tile-format.md)）は
それぞれ動くが、**繋がっていない。**

繋げるコードをどこに置くかが問題になる。`flightsim-fdm` は `flightsim-world` を
参照できない（[ARCHITECTURE.md §2](../../ARCHITECTURE.md#2-クレート構成と依存の向き)）。
これは慣習ではなく CI が検査する規約であり、FDM が地形を自分で引きに行かないことで
FDM 単体のテストが GUI もデータもなしに回る、という性質を守っている。

## 選択肢

| 案 | 評価 |
|---|---|
| `flightsim-fdm` に地形参照を足す | **却下。** 規約違反。FDM のテストが地形データを要求するようになり、決定論も揺らぐ |
| `flightsim-world` に FDM 連携を足す | **却下。** world が fdm に依存することになり、兄弟間の横断依存になる |
| `flightsim-app`（Bevy 層）に書く | **却下。** ヘッドレスで走らせられない。M1 の完了条件そのものを満たせない |
| **新クレート `flightsim-sim`（採用）** | `core` + `fdm` + `world` の上に乗る純 Rust。ヘッドレスで回る |

## 決定

**`flightsim-sim` を新設する。** Bevy に依存しない純 Rust。

```
                    app (Bevy)
                        │
        ┌───────────────┼───────────────┐
        ▼               ▼               ▼
     render          input             ui          ← Bevy 依存層
        └───────────────┼───────────────┘
                        ▼
                       sim          ← 地形と FDM の結線。純 Rust
                  ┌─────┴─────┐
                  ▼           ▼
                world        fdm     ← 純 Rust
                  └─────┬─────┘
                        ▼
                      core
```

責務は 3 つに絞る。

1. **接地平面の生成** — 地形から `Environment::with_ground_plane` に渡す
   基準点・標高・勾配を作る
2. **固定ステップ駆動** — `FixedStep` で FDM を回す（ADR-0004）
3. **軌跡の記録** — ヘッドレス実行の出力

**M2 で Bevy 層が乗る際も、この結線を再実装しないこと。** `app` は `sim` を
呼ぶだけにする。同じ結線が 2 箇所にあると、片方だけ直されて挙動が食い違う。

### 接地平面の勾配は有限差分で求める

基準点から北・東へ一定距離だけ離れた 2 点の標高差から勾配を出す。

探査距離は既定 10 m。**機体の脚間距離と同程度**にするのが要点で、脚が実際に
感じる面と、FDM に渡す平面を一致させるため。極端に大きくすると滑走路の
起伏が均され、小さくすると DEM の補間ノイズを拾う。

### 操縦は決定論的な閉ループで行う

「離陸 → 旋回 → 着陸」を開ループの舵角時系列で実現するのは非現実的
（機体は本質的に不安定で、同じ舵角列が同じ結果にならない）。
そこで **PD 制御の簡易フライトディレクタ**を持たせる。

壁時計時間・乱数・グローバル状態を参照しないので、FDM の決定論は保たれる
（ADR-0004）。これは操縦支援の実装ではなく、**回帰テストのための駆動装置**。

## 帰結

**受け入れるコスト**

- クレートが 1 つ増える。ビルド対象と CI 時間がわずかに増える
- フライトディレクタの制御ゲインは機体に依存する。機体を増やすたびに
  調整が要る。**実機の自動操縦の再現ではない**ことを明記しておく
- 有限差分の勾配は、DEM のバイリニア補間がセル境界で微分不連続なため、
  セルをまたぐ瞬間に段階的に変わる。滑走路スケールでは問題にならないが、
  滑らかな勾配が要る用途（将来の車輪の転がり抵抗の精密化など）では
  補間方式を上げる必要がある

**得られる保証**

- ヘッドレスで実地形の上を飛べる。10 分の飛行を数秒で検証できるので、
  地形と物理の統合に対する回帰テストが CI に載る
- M2 の Bevy 層は結線を再実装せず `sim` を呼ぶだけでよい
- 地形が無い領域（海上）でも破綻しない。標高が引けない場合は
  楕円体高 0 m として扱う契約を `sim` が持つ
