# Original Swift Sport package

The profile and embedded static exterior are exact copies of this repository's
original Swift Sport assets, retained without transformation or reserialization:

- assets/aircraft/swift_sport.json: 2,717 bytes, SHA-256 319257c8363cf5b0d480b914796f43bbec8b7935adc32d095c706c86b8c3e663
- assets/aircraft/swift_sport.glb: 229,192 bytes, SHA-256 9f30f6f9babe87a54d0f1f5da104f719d7e99cb05aada2848f8ea88b0bf9e3b1

Source snapshot: fff0f6d2c5433248090867391f4cca94075ffbff.
The model was made from original procedural primitives/materials in Blender
4.3.2 using tools/blender/build_swift_sport.py. It contains no third-party mesh,
texture, logo or branded aircraft design. The project-authored representative
profile is fictional, not certified real-aircraft performance data.

ATTRIBUTION.md's Original Swift Sport section licenses these original assets
under MIT OR Apache-2.0. Both complete license texts are included. This package
records that asset permission; it does not grant release clearance for a game
binary, dependencies, fonts, terrain, music or a distribution platform.

Package identity hashes manifest bytes and all declared members. Physical
identity and replay compatibility still come from the unchanged profile/FDM and
replay loaders. No physics revision or replay data is rewritten by packaging.
