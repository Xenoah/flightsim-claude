LLVM libc dyadic floating-point implementation adapted in pxfm 0.1.30

pxfm src/dyadic_float.rs contains a Rust, fixed-128-bit adaptation of LLVM libc dyadic_float.h, including fast_as_f64 corresponding to fast_as<T>. The Rust adaptation changes language, types, helper calls and exception-handling details. This acknowledgement describes the observed adaptation; it does not assert a particular historical import commit.
